## 按模块了解功能

先看[第一版功能清单](./第一版功能清单.md)，按以下顺序阅读：

1. **客服中心**：会话工作台、待办事项、历史会话记录。
2. **电商管理**：客户管理、商品管理、订单管理、支付记录、物流管理、退款售后、库存流水。
3. **AI 与知识**：AI 模型配置、知识库、客服知识、知识切片、召回测试、Prompt 模板。
4. **分析与反馈**：数据分析、回复路由记录、回答反馈、待跟进问题。
5. **平台设置**：店铺接入、客服账号、接待规则、自动打招呼、检索设置。

每个子模块说明能查看什么、可以做什么以及需要注意的规则，并标明 AgentServe 原有、需要调整或需要新增的部分。
