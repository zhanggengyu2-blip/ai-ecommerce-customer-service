# 前端交互预览

更新日期：2026-10-21。

预览地址：<http://127.0.0.1:6173/?preview=workbench>，也可使用 `?preview=app`。无需登录、不依赖后端，原登录页保留新版预览入口。

## 按模块体验

| 模块 | 页面与交互 |
| --- | --- |
| 客服中心 | 会话搜索和筛选、接入与完结、AI 回复辅助、独立草稿、图片、相关订单、客服工单；待办列表创建和编辑工单、待完成／已完成筛选及手动标记；全店历史会话、对应 AI 回复路由 |
| 电商管理 | 已有客户资料编辑，新增商品支持图片及多个规格（各自价格与库存）、上下架和库存调整；创建订单、支付、发货、取消、申请全额退款；支付、物流、退款和库存记录及相应操作 |
| AI 与知识 | 三类模型配置与 Key 遮挡、全店 AI 接待开关；知识库分类、文章编辑与发布、有效期、每篇分段设置及手动预览；已发布切片维护、召回测试、完整 Prompt 模板编辑 |
| 分析与反馈 | 基于示例记录计算的接待与完结指标、趋势、工单和 Token；回复路由详情、单条回答评价、当前待跟进问题 |
| 平台设置 | 店铺接入说明、客服账号、只读接待规则、自动打招呼及全店 Top K／Score 设置，使用同一页面的五个页签 |

页面之间共享数据：会话创建的工单进入待办列表；待办标记完成同步到会话侧；订单操作同步关联订单；发布与编辑切片影响召回测试；接入会话后从等待人工的待跟进列表移出。工作台持续保留，切换到其他模块不会清空会话草稿。

工单只记录诉求，不执行退款、修改订单或关闭会话。电商操作仍按原有范围演示，不因工单类型增加换货、补发、部分退款等执行流程。

## 使用边界

- 页面已移除开发场景菜单和阶段提示；刷新页面会恢复初始内存数据。
- 模型配置只保留示例服务商、模型与 Key 尾号，不保存输入的完整 Key。配置校验不请求服务商；请使用任意示例文本体验。
- 召回测试使用已发布、启用且在有效期内的知识做本地内容匹配，使用归一化文本匹配得分验证必填 Score（默认 0.30）过滤、Top K 和逐轮切片查看。该得分不是向量模型或重排模型输出；真实语义检索及模型回复待接口对接；测试不创建会话、工单或业务记录。
- 新知识的用途说明在本地发布时生成，已有知识可以修订；真实解析、向量化和后台发布任务尚未接入。
- 账号维护不会创建实际登录凭证；真实多客服并发接入、停用鉴权、登录端替换、自动计时和断线接管仍需后端实现。
- 数据分析来自本地示例会话、评价、工单和操作记录；未知 Token 显示「—」，不展示费用或估算节省工时。

## 2026-10-21 交互变更

- 早先的蓝色方案（已由下方中性主题覆盖）：全店配色调整为更鲜明的蓝色，文字统一为深标题、正文与辅助说明三档，状态文字保留语义色；侧栏、聊天区、表头与选中状态增加区分。下拉、日期浮层、弹窗、回复路由与图表同步处理。29 项显示检查通过，涵盖代表性文字对比度、浮层及窄屏布局；类型检查与生产构建通过。

- 完结会话增加二次确认；日期与时间控件整框可点击，知识有效期问号点击可展开；历史消息使用中性浅灰底色。侧栏 AI 接待状态与店铺名称对齐，点击进入模型配置。
- 模型页三处说明重写，AI 关闭时提示完成三个模型配置；Score 移除独立必填标签但保留校验；回复路由的 AI 请求、上下文与结果文字分层对齐。
- 全局布局按确认图统一：标题和说明进入顶部栏，AI 接待状态移到侧栏店铺下方，列表操作进入卡片筛选区右侧；模型、Prompt、召回及知识编辑的按钮进入对应卡片。

- 会话列表按客户聚合；重新发起固定新建接待记录，保留之前的消息和旧事件工单。
- 会话详情与回复路由弹窗共用，来源页面不跳转；路由详情直接复用原 TraceDetail 组件，通过独立本地快照加载器供给数据。无完整快照的记录不伪造成功节点。
- 商品以 groupId 聚合规格；新增支持图片和多个规格，列表取首个规格售价；订单与库存仍使用稳定的规格 ID。移除新增客户入口。
- 历史摘要展示独立的一句话概括；新完结会话尚无模型摘要时显示“待生成摘要”。
- 客服头像支持 JPG／PNG／WebP（2 MB），知识上传扩展到 UTF-8 纯文本格式；Prompt 先进入编辑模式再修改。
- 自动打招呼默认关闭，Score 必填、默认 0.30，错误说明放在对应字段旁。

## 2026-10-21 中性主题落地

按已确认效果图，将五个模块统一为「灰白底＋靛蓝点缀」：

- 页面背景 `#F5F5F7`、侧栏 `#FAFAFB`、聊天与历史消息区域 `#F4F4F6`、表头 `#F7F7F9`；卡片与消息气泡保持白色。
- 主题色 `#4F46E5`，用于按钮、链接、选中导航、页签与输入焦点；选中会话使用近白底与靛蓝左边线。
- 标题、正文、辅助文字分别采用 `#18181B`、`#303039`、`#62626E`。绿色成功、黄色等待、红色错误继续表达各自状态。
- 将页面中的颜色接入公共变量；Element Plus 的下拉、日期面板、弹窗、抽屉、提示和加载显示，以及回复路由节点与趋势图同步继承主题。
- 补齐召回页 Tooltip（提示浮层）组件与回复路由 Loading（加载显示）指令的本地注册。

验证：25 个桌面页面的背景、侧栏、表头与主要按钮显示一致；977／390 像素下检查六个代表页面，均未出现页面横向溢出，并检查手机导航。下拉、知识日期面板、回复路由节点与流程图已浏览核对。21 组正文／状态文字配色的对比度均达到 4.5:1，最低 4.54:1；不把禁用控件当作正常正文进行检查。补齐组件注册后，重新检查召回得分提示与节点参数加载，未出现新的浏览器警告或错误；类型检查与生产构建通过。实际截图与检查记录保存在 `../output/theme-2026-10-21/`。
